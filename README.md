# Salah Tracker

Initial production-oriented foundation for a cross-platform salary tracker built with React Native and Expo.

## Stack

- Expo SDK 57
- React Native 0.86
- React 19.2.3
- TypeScript
- Expo Router
- NativeWind 4
- Tailwind CSS 3
- Zustand
- react-native-reanimated
- react-native-safe-area-context
- ESLint
- Prettier
- npm

Supabase, authentication, database, and persistent storage are intentionally not configured yet.

## Requirements

- Node.js 24.19.0 (or another supported Node version for Expo SDK 57)
- npm
- Expo Go for initial device testing

## Install

```bash
npm install
```

## Run

```bash
npm start
```

Scan the QR code with Expo Go.

## Validation

```bash
npm run lint
npm run typecheck
npm run format:check
```

## App identity

- Name: Salah Tracker
- iOS bundle identifier: `com.sakib.salahtracker`
- Android package: `com.sakib.salahtracker`
